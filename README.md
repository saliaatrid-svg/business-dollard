## Règles du projet

1. **Rien n'est signé** (bail, convention, engagement financier) avant d'avoir les réponses écrites du Département et la preuve de la demande (au moins 4 habitants intéressés).
2. **Un projet à la fois** : Sézanne d'abord ; la Guadeloupe démarre quand Sézanne avance sans toi sur tout.
3. **Structure dédiée** : l'habitat sera porté par une structure distincte de DMS (association ou société), pour ne pas mélanger les pertes de DMS et pour garder la possibilité d'une autorisation SAD.
4. **Confidentialité** : aucun nom de client ni donnée personnelle dans ce dépôt. Les données de DMS (comptes, analyse d'activité, dossiers) restent dans le Drive.
5. **Les sources non vérifiées** sont marquées « à vérifier » dans les fichiers. Les mettre à jour après chaque réponse officielle.
