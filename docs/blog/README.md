## Règles appliquées (à conserver pour les prochains articles)
- Aucun chiffre ni statistique sans source officielle.
- Aucun conseil médical : renvoi vers un professionnel de santé.
- Aucune promesse de service, de prix, d'avantage fiscal ni d'avance immédiate.
- Pas de public non couvert mis en avant (seniors dépendants, personnes handicapées) pour les services de DMS en prestataire, tant que le Département n'a pas répondu.
